# Data Structures in C Implementation
## Custom implementation of Dynamic Arrays, Linked Lists, and Hash Maps within C.  
    Each respective data structure can be found standalone within separate folders.

### Dynamic Array

-`dyn_arr_header.h` contains the `typedef struct` for the DynArr struct, as well as the declarations for the ADT functions.

-in `dynamic_array.c`, main samples some of the implemented functions, including appending integers that were pseudo-randomly generated with `rand()`.
